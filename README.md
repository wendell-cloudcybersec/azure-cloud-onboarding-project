# Azure Cloud Onboarding Project

## Overview

This project demonstrates the setup and exploration of Microsoft Azure cloud services using the Azure Free Tier account.

The project includes:
- Azure account setup
- Resource Group creation
- Azure Storage Account deployment
- Cost Management exploration
- Cloud governance concepts
- Shared Responsibility Model understanding
