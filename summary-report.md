# Azure Cloud Onboarding Project Report

## Introduction

This project involved setting up and exploring the Microsoft Azure cloud platform using the Azure Free Tier account.

---

## Azure Region Selected

I selected the UK South region because it is geographically closest to my location. Choosing a nearby region helps reduce latency and improves resource performance.

---

## Resource Deployed

I deployed an Azure Storage Account as my cloud resource.

Storage accounts are used for storing files, blobs, backups, and application data in the cloud.

---

## Understanding the Shared Responsibility Model

The Shared Responsibility Model explains which security responsibilities belong to Microsoft Azure and which belong to the customer.

### Microsoft Responsibilities
Microsoft is responsible for:
- Physical datacenter security
- Cloud infrastructure
- Hardware maintenance
- Networking infrastructure

### Customer Responsibilities
I am responsible for:
- Managing access permissions
- Protecting account credentials
- Configuring resources securely
- Managing uploaded data

For my deployed Storage Account, Microsoft secures the underlying cloud infrastructure while I am responsible for controlling who can access the storage account and how the data is managed.

---

## Understanding IaaS, PaaS, and SaaS

### IaaS
Infrastructure as a Service provides virtualized computing resources such as Virtual Machines.

### PaaS
Platform as a Service provides platforms for building and deploying applications.

### SaaS
Software as a Service provides ready-to-use software applications over the internet.
